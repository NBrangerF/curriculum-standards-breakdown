# 课堂诊断（2026-11）

上课先问一道题，看清全班怎么想；批完作业，明天开课用 5 分钟补上。调研见 artifact「批完就用」(https://claude.ai/artifact/3KwJNVAEPV8PX9ZAbgyb3k)。

## 为什么这样做

- 证据：作业和小测要真正改变教学，靠离课堂近、能马上变成动作的证据（ASSISTments 缅因州随机试验 g = 0.18，老师按错题第二天讲评；EEF Embedding Formative Assessment +2 个月）。看错因比看正确率有用（Eedi 的诊断题：每个错误选项对应一种迷思）。
- 国内主流产品（智学网个册、极课、点阵笔、希沃批阅机）把力气花在采集上，要采购硬件；最弱的一环是“明天做什么”。
- 用户的两条要求（2026-11-01）：题库要事先备好；输出要适合大班，能直接用电脑、投影、PPT 呈现。

所以：
1. **大班作答方式**：没有学生设备也能 30 秒看清全班——手势 1–4、拇指上下、举草稿纸。题型只有四种：`choice`（四选一，错项对应错法）、`judge`（同意吗：评判一份做法）、`step`（哪一步开始错）、`write`（写答案举起来，列出常见错答）。
2. **投影优先**：`/checks/present` 是 16:9 的舞台，尺寸全用 cqh（舞台高度的 1%），像幻灯片一样缩放，4:3 投影自动加黑边；白底（亮教室）/黑底；翻页笔的 PageUp/PageDown、B（黑屏）都能用；数字键 1–4 记人数（Shift 加 5）；N 打开教师提示（错法的原因和应对，只在老师需要时显示）。
3. **一题几屏**：题目 → 揭晓（正确答案、每个错项“可能想的是”、正确做法、请答错的同学说想法）→ 比一比（小明的典型错法 vs 小红的正确做法，先让全班判断再标出）→ 阶梯练习（① 基础 ② 巩固 ③ 挑战，全班在练习本上从 ① 做起；大班里用“阶梯”代替分组发小条）。
4. **PPT**：同一套幻灯片导出为可编辑的 .pptx（pptxgenjs，按需加载），微软雅黑；分数写成 a/b、幂写成 x²；需要按键分步的屏（比一比、阶梯练习）在 PPT 里拆成两页；教师提示放在备注里。
5. **批完就用**（`/checks/after`）：批改时按单元点“看到的错法 + 大约多少人”（没看到 / 几个人 / 不少人 / 一大半），不按题数人数、不记学生名字。生成“明天开课 5 分钟”：最多处理两种错法，第一种走完整一轮（开课一问、揭晓、比一比、阶梯练习），第二种课尾再查一题。记录只存在本机 localStorage（`kebiao.checks.records`），“回看”换一道针对同样错法的题再查。

## 题库

- 位置：`data/checks/<学科>/<文件>.json`。学科清单、题号前缀、对应的课标文件和教材版本在 `src/features/checks/subjects.js`（校验脚本和页面共用）。怎么写一道题：`data/checks/README.md`。
- 两种编排（2026-11-01 用户要求“全学科都要有”后扩展）：
  - 按册：语文、道德与法治、历史（统编版），数学、英语（3–6 年级 PEP、7–9 年级人教版）、物理、化学、生物学、地理（人教版），科学（教科版）。文件名 `5a.json`（五上）、`5b.json`（五下）、`9.json`（全一册）；`unit` 必须是库里这一册的单元（`public/data/textbooks/national-lessons/`）。库里没有目录的册（英语八下、九下，科学三下）不出题；目录不全的册（新版本陆续上线，如语文五上、九上）只给列出的单元出题。
  - 按学段：信息科技、劳动（库里没有教材）、体育与健康、音乐、美术（各地版本不同，库里目录不全）。文件名 `3-4.json`；艺术用自己的学段 `1-2`、`3-5`、`6-7`、`8-9`。`unit` 是课标这个学段的学习任务、任务群或内容模块。
- 每个文件：`book`（`{grade, term}` 或 `{band}`）、`misconceptions`（id、name、why、move）、`items`。错法 id 在学科内唯一，可以被同学科其他册的题引用。
- 题目字段见 README；题号 `<前缀>-<文件名>-NN`（`ma-5b-05`、`ph-9-03`、`la-3-4-02`）。
- 标记：数学、物理、化学、生物学、科学、地理用数学标记（`{5/6}`、`x^2`、`H_2O`、`Fe^{3+}`、化学方程式条件 `=[点燃]=`、`-[加热]->`，见 `src/features/checks/mathText.js`）；语文、英语、道德与法治、历史、信息科技、体育与健康、音乐、美术、劳动原样显示（页面用 `MarkupContext`，PPT 用 `markup: 'plain'`）。
- 校验：`npm run check:checks`（`scripts/checks/bank.mjs --check`，`--subject english` 只查一科并列出还没有题的单元）——要点编码存在且属于本学科（音乐只用 AR-…-MU-，美术只用 VA/FM），要点学段和年级相差不超过一年，单元在册目录或学段任务里，每个错项都有错法，`verify` 精确验算为真，投影文字宽度（汉字算 1，字母数字算 0.55），答案位置不集中，同意吗题不全是不同意。构建：`build:public-data` 最后一步写 `public/data/checks/{<学科>.json,index.json}`（index 有每科的册/学段和 `by_point`）。

## 接口

- 页面：`/checks?subject=&book=`（先选学科，再选册或学段、单元；`?grade=&term=` 的旧链接仍可用，`?point=` 按要点）、`/checks/present?q=&with=contrast,ladder[,first]&title=&back=`（一套放映只放一科，按第一个题号定学科）、`/checks/after?subject=&book=&unit=`（记录带学科，只列当前学科的记录）。
- 入口：备课导航“课堂诊断”；课标页每条要点下“课堂诊断题 n 道”（各学科）；教材页“课堂诊断题”（这一册或它所在学段有题时）；AI 备课的课时卡片里列出这一课可用的题。
- API：`GET /api/v1/checks?subject=&code=&grade=&term=&q=&limit=`（subject 可写 slug 或学科名；不给 subject 时按 code 判断学科，都不给就在所有学科里找）、`GET /api/v1/checks/{id}`；MCP 工具 `get_check_questions`（subject / code / grade / topic）。

## 怎么写出来、审过来的（2026-11-01 扩到全学科）

- 20 个子任务按 `data/checks/README.md` 分头写题，每个只写自己的文件，写完必须通过校验；每部分再由另一个子任务逐题审（答案、事实、错法、安全、文字）。新写的 875 题审下来改了 401 题；原来的数学 197 题按同样标准补审，改了 124 题。
- 有教材的学科对照了库里教材的逐页全文（移动硬盘 `/Volumes/X9 Pro/kebiao-library/derived/textbook-content-v2/<sha>/pages.jsonl`，每行一页，`text` 字段；`manifest.json` 里的 `edition_id` 对应 `public/data/textbooks/index.json`）。查出的典型问题：按旧版注释判反的文言题、新版已删的内容（七下“法律的特征”、九年级物理的串联总电阻公式）、照搬教材例题的数字、写错的日期。
- 道德与法治、体育与健康、劳动、信息科技里正确选项常常最长；把错项写成学生会说的完整的话后，“专挑最长的”只能猜对和瞎猜差不多的题数。校验对位置、同意吗真假比例、最长选项三种偏向报警告。

## 还没做

- 题目由 AI 写、AI 审，对照了教材全文，但没有真实的老师或教研员审读；欢迎老师报错。
- 题目按库里那一版的单元编排。2026-11-01 合并 main 时，库里换上了 82 册最新印次（人教 数学·英语·理化生地、教科 科学等的新版），190 道题随之对到新版单元：挪单元、按新版换年级（如多边形内角和到八下）、新版不再教的内容改题。以后库里再换版，跑 `npm run check:checks`，对不上单元的题会报错。
- 目录不全的册只给列出的单元出题（语文、道德与法治的五上、六上、九上等）；英语八下、九下和科学三下库里没有目录，暂时没有题。
- 只有文字题；需要看图的内容（观察物体、电路图、地图）暂时不出。舞蹈、戏剧没有单独的题库，影视并在美术里。
- 学生端作答、班级统计、长期档案都没有做；批完就用的记录只在本机，按学科分开。
