# 课标首席 · 课标与教材对位、依标备课顾问

WorkBuddy 专家，依据《义务教育课程标准（2022年版2025年修订）》工作。四项能力：

1. **查真实课标**：要点原文、页码、学业要求，一字不改。
2. **课标与教材对位**：教材的一课主要在教哪几条课标，附教材原话和页码；也能反查一条课标在哪一课教。
3. **依标写教案**：先列依据请老师确认，再起草，每个目标标出依据编码。
4. **精修老师的教案**：保留老师的结构和学校模板，对齐课标、补缺、改超标，标出每处改动。

数据来自 kebiao（https://www.kebiao.org）。专家内置 kebiao 的只读 MCP 服务（https://www.kebiao.org/mcp）：不需要账号，只发送查询词，不收集个人信息。召唤专家时点一次「连接」即可。
