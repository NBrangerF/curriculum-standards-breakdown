# 依标备课｜kebiao

WorkBuddy 专家，帮义务教育阶段（1–9 年级）老师依据《义务教育课程标准（2022年版2025年修订）》备课。

## 能做什么

| 老师说 | 交付 |
| --- | --- |
| 「人教版五下《分数的基本性质》对应哪几条课标？」 | 这一课主要在教、也涉及的课标要点：原文、课标页码、教材原话 |
| 「初中物理浮力的课标要求是什么？」 | 要点原文、页码、学段，需要时附学业要求和 2025 修订改动 |
| 「帮我写《观潮》第一课时的教案」 | 一份完整教案：课标依据、学习目标（标依据编码）、按 45 人大班设计的教学过程、当堂检测、作业时长 |
| 「帮我核对这几条教学目标」「精修我的教案」 | 诊断（每条附依据）、修改对照表、保留原结构的修改后全文 |

## 怎么用

- 一句话说清学科、年级、教材版本和课题即可；没说的，专家按默认值补上并写明（统编版或人教版、45 人、40 分钟、第 1 课时）。
- 要核对或精修，请把教案或目标贴在消息里。
- 每个回答都附 kebiao 链接，可回到 https://www.kebiao.org 核对原文。

## 能力边界

- 只覆盖义务教育 14 门学科的课标；不覆盖高中、幼儿园课标。
- 课标原文、编码、页码只引用 kebiao 返回的内容，查不到会明说，不编造。
- 教材对位和课堂学习目标是 AI 判断，标「待核验」；教案是初稿，需教师审核后使用。
- 不提供考试原题和押题；不收集学生姓名、成绩等个人信息。

## 运行条件

数据来自 kebiao 的只读接口（https://www.kebiao.org/api/v1/plugin/ ），不需要账号或授权，只发送查询词。如果已连接 kebiao 连接器，会优先用连接器的工具。断网时只能查包里自带的课标要点快照，没有教材对位。
