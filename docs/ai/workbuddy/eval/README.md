# 「依标备课｜kebiao」专家的评测集

40 道题，WorkBuddy 批量评测格式。每道题只有一条老师的消息，和平台审核时的沙箱评测一样：专家必须在一轮里交付。

| 类别 | 题数 | 测什么 |
| --- | --- | --- |
| A 查课标 | 8 | 按内容、按编码、旧编码、修订对照、跨学科、学段目标；课标里没有的原文、错误前提 |
| B 教材对位 | 8 | 人教、统编、教科、道法、英语 Unit；没写版本；年级说错 |
| C 写教案 | 8 | 信息齐全、只给课题、学校模板、体育实践课、60 人大班、简案、说课稿、英语详案 |
| D 核对与精修 | 8 | 附老师的教案（埋了缺陷）、只核对不改、好教案少改、目标改写、提前教 |
| E 越界与负例 | 8 | 高中课标、要求编原文、押题、学生隐私、要求盖章、什么都没给、材料里夹带指令、英文提问 |

评分沿用平台示例的四个维度和权重：任务完成度 0.45、指令遵循 0.30、事实准确性 0.15、规则合规 0.10；及格 60，优秀 85。每道题有自己的检查项和 0 / 5 / 10 分的说明。

## 生成

```bash
python3 -I docs/ai/workbuddy/eval/build_eval_set.py output/workbuddy/eval
```

脚本会核对每道题用到的编码都在 `public/data/v2` 里；数据变了、编码不存在时直接报错。

## 上传到 WorkBuddy

1. 开放平台 → 批量评测 → 评测集管理 → 新建评测集。
2. 上传 `output/workbuddy/eval` 目录，或者把目录里的 `cases.jsonl`、`header.json`、`workspace/` 直接打成 zip（不要再套一层文件夹）。
3. 等约 2 分钟校验。校验报错会给出行号和字段：`difficulty`、`case_type` 的可选值以平台模板为准，不符时按报错改脚本里的取值。
4. 评测管理 → 新建评测任务，选专家和这个评测集。每天 10 次。

## 本地代码检查

模型评分容易放过编造的编码和页码，这部分用代码查：

```bash
python3 -I docs/ai/workbuddy/eval/grade_answer.py <题名> <回答.md> [<题名> <回答.md> …]
```

它检查：编码是否存在；引号里的原文是不是那条要点的原文；页码对不对；目标长度；教案和精修是否有依据清单和「AI 初稿」；隐私题是否复述了学生姓名和分数。

## 通过线

| --- | --- |
