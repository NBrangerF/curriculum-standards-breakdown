# kebiao 课标查证

kebiao 收录义务教育 14 门学科的课程标准（2022年版2025年修订）：513 条标准、2,520 条要点，要点逐字取自课标原文并标页码；新教材逐课对到要点，并附教材原话。所有工具只读，不需要老师的任何个人信息，也不需要授权。

## 先选工具

| 老师在问 | 用这个工具 |
| --- | --- |
| 教材里的一课对应哪些课标（「人教版五下《分数的基本性质》」） | `find_textbook_chapter` |
| 某个教学内容的课标要求（「初中物理 浮力」） | `search_standards` |
| 一条标准的全部要点、学业要求 | `get_standard` |
| 一条课标在哪些教材的哪一课教 | `get_textbook_links` |
| 自己写的学习目标对不对课标 | `check_objectives` |
| 课堂诊断题 | `get_check_questions` |
| 2025 修订改了什么 | `compare_versions` |
| 一门学科有哪些标准、学段目标 | `list_standards`、`get_stage_goals` |

## 引用规则

- 课标原文、编码、页码、教材原话只复制工具返回的文字：原文一字不改，放在引号里，后面写编码和页码，附工具给出的 kebiao 链接。
- 编码不要自己拼。编码不存在时，`get_standard` 会返回同学科、同学段的真实编码，从里面选。
- 工具没找到就如实告诉老师没找到，并说明下一步（换个说法、核对年级或版本），不要凭记忆补写课标。
- 标「kebiao 整理」的标准句是用课标原词写的概括，不是课标原句。教材对应和课堂学习目标是 AI 判断，标「待核验」。

## 工具

### find_textbook_chapter - 从教材的一课找课标

把老师的原话直接放进 `query`，工具会认出版本、年级、册次和学科，例如「人教版 八年级上册 光的反射」「统编版四年级上册《观潮》」「五下 分数的基本性质」。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| query | string | 是 | 老师对这一课的说法；只写课题也可以 |
| subject | string | - | 学科，如「物理」 |
| grade | string | - | 年级，如「八年级」「8」 |
| edition | string | - | 教材版本，如「人教版」「统编版」「北师大版」 |
| volume | string | - | 册次：上册、下册、全一册 |

返回这一课「主要在教」「也涉及」的要点：要点原文和课标页码、教材原话和出处、这一课的课堂学习目标；再列机器按目录对齐的章节。找不到时会说明同名的课在哪本书里，据此核对年级或版本。

### search_standards - 按内容检索课标

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| query | string | 是 | 教学内容或主题，如「初中物理 浮力」 |
| subject | string | - | 学科，如「数学」 |
| stage | string | - | 学段或年级，如「3-4」「五年级」「初中」 |
| limit | integer | - | 返回条数，1–10，默认 5 |

### get_standard - 查看一条标准

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| code | string | 是 | 标准编码（MA-S2-NA-02）、要点编码（MA-S2-NA-02.1）或 2022 年版旧编码 |

返回标准句、全部要点原文和页码、学业要求和链接。

### get_textbook_links - 一条课标对应的教材

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| code | string | 是 | 标准或要点编码 |

返回哪些教材的哪一课在教它，附教材原话。

### check_objectives - 目标体检

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| objectives | string | 是 | 老师写的学习目标，一行一条 |
| subject | string | 是 | 学科 |
| grade | string | - | 年级 |
| topic | string | - | 课题，如「分数的基本性质」 |
| codes | string[] | - | 这节课依据的要点编码 |

逐条给出依据的要点和原文里的词、程度比要点高还是低、缺的条件/行为/程度，以及一条「学生能……」的改写；另查主语不是学生、看不见的动词、课标写明「不包括」的内容。每分钟调用次数有上限，忙时会提示稍后再试。

### get_check_questions - 课堂诊断题

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| subject | string | - | 学科 |
| code | string | - | 要点或标准编码 |
| grade | integer | - | 年级 1–9 |
| topic | string | - | 关键词，如「通分」 |
| limit | integer | - | 题数，默认 3，最多 8 |

编码、年级、关键词至少给一个。每道题的错误答案都对应一种常见错法，附放映链接。

### compare_versions - 2025 修订对照

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| code | string | 是 | 标准或要点编码 |

### list_standards - 一门学科的标准

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| subject | string | 是 | 学科名或代号，如「数学」或 math |
| stage | string | - | 学段，如「第二学段」「3-4」 |

### get_stage_goals - 学段目标

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| subject | string | 是 | 学科 |
| stage | string | - | 学段或年级 |

### list_subjects - 学科列表

无参数。返回 14 门学科、学段和条数。

## 常见情况

- 返回「没有找到这一课」并列出同名课所在的书：多半是年级或版本说错了，按列出的书再查一次，或请老师确认。
- 返回「这一分钟体检的人有点多」：等一分钟再调用 `check_objectives`。
- 返回「没有这个编码」：从它列出的真实编码里选，或先用 `search_standards` 检索。
