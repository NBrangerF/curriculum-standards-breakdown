# kebiao 课标查证

kebiao 收录义务教育 14 门学科的课程标准（2022年版2025年修订）：513 条标准、2,520 条要点，要点逐字取自课标原文并标页码；147 册新教材逐课对到要点并附教材原话。所有工具只读，不需要老师的任何个人信息。

## 怎么用

- 老师说的是教材里的一课：先用 `find_textbook_chapter`。
- 说的是教学内容：用 `search_standards`。
- 需要原文细节：再用 `get_standard`。
- 引用时写出编码（如 MA-S3-NA-01.3）、要点原文（一字不改，放在引号里）、页码和工具返回的 kebiao 链接。
- 工具没找到就说没找到，建议换个说法，不要编造编码或原文。
- 标「kebiao 整理」的标准句是用课标原词写的概括；教材对应是 AI 判断，标「待核验」。

## 工具

### find_textbook_chapter - 按教材课题找课标

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| query | string | 是 | 教材版本、年级册次和课题，如「人教版 五年级下册 分数的基本性质」 |
| subject | string | 否 | 学科 |
| grade | string | 否 | 年级，如「五年级」「8」 |

返回这一课「主要在教」「也涉及」的要点、教材原话和页码。

### search_standards - 检索课标

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| query | string | 是 | 教学内容或主题，如「初中物理 浮力」 |
| subject | string | 否 | 学科，如「数学」 |
| stage | string | 否 | 学段或年级，如「3-4」「五年级」「初中」 |
| limit | integer | 否 | 返回条数，1–10，默认 5 |

### get_standard - 查看一条标准

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| code | string | 是 | 标准编码（MA-S2-NA-02）、要点编码（MA-S2-NA-02.1）或 2022 年版旧编码 |

返回标准句、全部要点原文和页码、学业要求和链接。

### get_textbook_links - 标准对应的教材

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| code | string | 是 | 标准或要点编码 |

返回哪些教材的哪一课在教它，附教材原话。

### list_standards - 列出一门学科的标准

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| subject | string | 是 | 学科名或代号，如「数学」或 math |
| stage | string | 否 | 学段，如「第二学段」「3-4」 |

### get_stage_goals - 学段目标

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| subject | string | 是 | 学科 |
| stage | string | 否 | 学段或年级 |

### compare_versions - 2025 修订对照

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| code | string | 是 | 标准或要点编码 |

返回这条标准在修订版里改了哪些要点。

### get_check_questions - 课堂诊断题

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| subject | string | 否 | 学科 |
| code | string | 否 | 要点或标准编码 |
| grade | integer | 否 | 年级 1–9 |
| topic | string | 否 | 关键词，如「通分」 |
| limit | integer | 否 | 题数，默认 3，最多 8 |

编码、年级、关键词至少给一个。每道题的错误答案都对应一种常见错法，附放映链接。

### list_subjects - 列出学科

无参数。返回 14 门学科、学段和条数。
