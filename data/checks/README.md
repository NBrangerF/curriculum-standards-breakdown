# 课堂诊断题库：怎么写一道题

课堂诊断题是上课开头（或讲完一个点）问全班的一道题。四五十人的大班，没有学生设备，全班用手势 1–4、拇指上下、或把答案写在草稿纸上举起来，老师半分钟就能看清：多少人懂了，没懂的人卡在哪种想法上。所以**每个错误答案都要对应一种真实的错法（迷思）**，老师看到“选 3 的人多”，就知道该接哪一种想法。

题目投影在 16:9 的屏幕上，也会导出成 PPT。页面、PPT、API 都从这里的 JSON 生成：`node scripts/checks/bank.mjs` 校验并写出 `public/data/checks/`。

| 数学 | math | ma | 人教版，每册一个 |
| 英语 | english | en | 人教版 PEP（3–6 年级）、人教版（7–9 年级），每册一个 |
| 道德与法治 | morality_law | ml | 统编版，每册一个 |
| 历史 | history | hi | 统编版，每册一个 |
| 地理 | geography | ge | 人教版，每册一个 |
| 科学 | science | sc | 教科版，每册一个 |
| 物理 | physics | ph | 人教版，每册一个；全一册写 `9.json` |
| 化学 | chemistry | ch | 人教版，每册一个 |
| 生物学 | biology | bi | 人教版，每册一个 |
| 信息科技 | it | it | 按学段：`1-2.json`、`3-4.json`、`5-6.json`、`7-9.json` |
| 体育与健康 | pe | pe | 按学段：`1-2.json` … `7-9.json` |

按册的学科，`unit` 必须是这一册在库里的单元名（`public/data/textbooks/national-lessons/` 的目录）。按学段的学科，`unit` 写课标里这个学段的学习任务、任务群或内容模块名（如“清洁与卫生”“身边的算法”“听赏与评述”）。

题号：`<前缀>-<文件名>-<两位序号>`，如 `ph-8a-05`、`ph-9-03`、`la-3-4-02`。

## 一个文件

```json
{
  "book": {"subject": "物理", "grade": 8, "term": "上", "edition": "人教版"},
  "misconceptions": [
    {"id": "density-halves-when-cut", "name": "以为切开后密度减半", "why": "只看到质量减半，忘了体积也减半。", "move": "让学生分别算出整块和半块的“质量 ÷ 体积”，比一比。"},
    {"id": "density-mixed-quantities", "name": "整块和半块的数混着用", "why": "切开后哪些量变了没理清，用整块的质量除以半块的体积。", "move": "先列表写出整块、半块各自的质量和体积，再相除。"}
  ],
  "items": [
    {
      "id": "ph-8a-05",
      "type": "choice",
      "unit": "第六章　质量与密度",
      "lessons": ["密度"],
      "points": ["PH-S4-MA-02.3"],
      "topic": "密度是物质的特性",
      "stem": "一块铁的质量是 158 g，体积是 20 cm^3。把它切成大小相等的两块，每块的密度是多少？",
      "options": ["3.95 g/cm^3", "7.9 g/cm^3", "15.8 g/cm^3"],
      "answer": 1,
      "wrong": {"0": "density-halves-when-cut", "2": "density-mixed-quantities"},
      "right": ["整块：ρ = m ÷ V = 158 g ÷ 20 cm^3 = 7.9 g/cm^3", "切开后质量、体积都减半，比值不变，还是 7.9 g/cm^3。"],
      "typical": ["每块质量 79 g，所以密度变成一半：3.95 g/cm^3"],
      "typical_error": "density-halves-when-cut",
      "ladder": [
        {"q": "一块铝 54 g，体积 20 cm^3，它的密度是多少？", "a": "2.7 g/cm^3"},
        {"q": "把这块铝锉掉一半，剩下部分的密度是多少？", "a": "2.7 g/cm^3"},
        {"q": "一瓶氧气用掉一半，瓶内剩余氧气的密度怎样变？为什么？", "a": "变为一半：质量减半，体积仍是整个瓶子"}
      ],
      "verify": ["158/20 == 7.9", "79/10 == 7.9", "79/20 == 3.95", "158/10 == 15.8", "54/20 == 2.7"]
    }
  ]
}
```

按学段的文件，`book` 写 `{"subject": "劳动", "band": "3-4"}`。

## 错法（misconceptions）

- `id`：英文小写加连字符，**在本学科内唯一**（各册共用一个命名空间，别的册已经定义过的错法可以直接引用）。
- `name`：老师批作业时要勾选的名字，**不超过 18 个字**，写学生“怎么想”或“怎么做”：“以为切开后密度减半”“把拟人当成比喻”“动词三单忘加 s”。不要写“概念不清”“粗心”这种看不出想法的名字。
- `why`：一句话，这种想法从哪来。
- `move`：一句话，课上怎么接——一个能马上做的动作、追问或反例，不要写“加强练习”。

## 题目字段

| 字段 | 说明 |
| --- | --- |
| `type` | `choice`（3–4 个选项，举几根手指）、`judge`（同意吗：评判一句话或一份做法，拇指上下）、`step`（3–4 步做法，从第几步开始错）、`write`（答案写在草稿纸上举起来） |
| `unit` | 单元（见上） |
| `lessons` | 课时名里的关键词（按册的学科必填，用来和 AI 备课的课时对上） |
| `points` | 课标要点编码（v2，如 `PH-S4-MA-02.3`），尽量用本学段的要点 |
| `topic` | 卡片标题，8–14 个字。老师选题时看；放映时题目页不显示（常常点出了规则），揭晓页才显示 |
| `stem` | 题干，一屏放得下 |
| `options` | choice 的选项 |
| `work` | judge：被评判的话或做法（1–3 行）；step：编号的每一步（3–4 行，不用写“第 1 步”） |
| `answer` | choice / step：正确选项或**第一处错的步骤**的下标（从 0 开始）；judge：`true`（应该同意）或 `false`；write：标准答案文字 |
| `wrong` | choice：`{"选项下标": 错法 id}`，**每个错误选项都要有**；judge：答案是 false 时写 `{"agree": id}`，答案是 true 时写 `{"disagree": id}`；write：`{"常见错答": 错法 id}` |
| `error` | step：错的那一步对应的错法 |
| `right` | 正确做法或理由，1–3 行 |
| `typical`、`typical_error` | choice / write：一份典型的错误做法（1–2 行，“比一比”页会把它和 `right` 并排放），以及它对应的错法（必须是 `wrong` 里出现的一个） |
| `ladder` | 阶梯练习，正好 3 级：① 基础 ② 巩固 ③ 挑战，每级 `q` 和 `a`，全班在练习本上从 ① 做起，三级一共 3–5 分钟 |
| `verify` | 有数值计算就写（数学、物理、化学），见下 |

投影宽度上限（一个汉字算 1，字母、数字、空格算半个）：题干 70，选项 26，`work` 每行 34，`right` 每行 44，阶梯题 56、答案 40。超了校验会警告，请改短。

## 怎样算一道好题

1. **错项要真**：每个错误答案都是有这种想法的学生真会给出的答案，不是凑数的。不要用“以上都对”“以上都不对”。
2. **答案唯一、无争议**：知识点按现行教材和课标的说法；拿不准的事实（年代、数据、人物、出处）就不要用。
3. **一题只诊断一件事**：题干短，一读就懂，不靠阅读量难住学生。
4. **原创**：不抄教材正文、练习册、教辅和试卷的题。古诗文（古人作品）可以引用诗句；现代课文只提篇名，或引用不超过 15 个字的短语，例句自己编。
5. **别让学生摸出规律**：正确选项不要老在同一个位置（四选项大约各占四分之一），也不要总是最长、最周全的那一个——错项也写成持这种想法的学生会说的完整的话；同意吗题大约三分之一应该同意。校验会对这几种偏向报警告。
6. **题型要配学科**：多数用 choice；“评判一句话/一个做法”用 judge；有步骤的计算、推理、改句用 step；短答案（一个数、一个字、一个词）用 write。
7. **阶梯练习**：三级由浅入深，紧扣同一个错法；答案短，老师能当场对。
8. **价值导向**：道德与法治、历史按教材的表述，不编造领导人或名人的话，不碰有争议的话题。

## 标记

- 数学、物理、化学、生物学、科学、地理用数学标记：`{5/6}` 分数，`x^2`、`cm^3` 上标，`H_2O`、`v_1` 下标，`Fe^{3+}`、`SO_4^{2-}` 离子，`√2` 根号，化学方程式的条件写 `2H_2 + O_2 =[点燃]= 2H_2O`，文字表达式写 `碳 + 氧气 -[点燃]-> 二氧化碳`。填空用“（　　）”，不要用下划线。
- 语文、英语、道德与法治、历史、信息科技、体育与健康、音乐、美术、劳动按原样显示，不解析标记：英语填空可以写 `____`，拼音直接写带调字母（ā á ǎ à）。

## 验算（verify）

`verify` 每行是一个用有理数精确计算、结果为真的式子：`+ − * / ^`、`%`、`sqrt()`（只限完全平方数）、`== != < > <= >=`、`and`，可以先赋值：`x = 3; 2*x + 5 == 11`。单位不写。物理、化学的每个数值答案，以及错项是怎么算出来的（如 `79/20 == 3.95`），都应该能验算。

## 写完检查

```bash
node scripts/checks/bank.mjs --check --subject physics
```

- `error` 必须全改掉；`warn` 尽量改掉（文字太长、答案位置太集中、错法没被用到）。
- `note` 列出还没有题的单元。总复习、活动课（★）可以不出题。

## 各学科提示

- **语文**：字音（多音字、易读错的字）、字形（形近字、同音字）、词义（近义词辨析、成语误用）、标点、修辞（比喻 vs 比较/拟人、夸张、排比）、句式（病句：成分残缺、搭配不当、语序不当、重复）、阅读方法（找中心句、概括段意、体会表达效果）、古诗文（诗句意思、文言实词虚词、古今异义）。题干里的例句自己编；古诗文可引原句。
- **英语**：语音（字母组合发音）、词汇（易混词）、语法（三单、复数、时态、介词、冠词、代词、比较级、句型）、交际用语（情景应答）、阅读策略。常见错法来自汉语迁移（漏冠词、漏时态标记、主谓一致）和过度类化（goed、childs）。选项写完整的短句或短语；题干可以用中文说明要求。
- **道德与法治**：概念辨析（权利与义务、违法与犯罪、法律与道德、自由与纪律）、情境判断（遇到某情况该怎么做、为什么）、常识性误解（“未成年人做什么都不用负责”）。表述按教材，一题一个清楚的道理。
- **历史**：时序（先后、朝代顺序、世纪换算）、因果（原因与结果、根本原因与直接原因）、史实与观点、史料类型（一手、二手）、以今度古、人物与事件对应。年代、人物、事件必须准确。
- **地理**：经纬度、方向（地图上的方向、经纬网定向）、比例尺、地球运动（四季成因不是距离远近、昼夜交替与四季）、气候与天气、地形与等高线、人口与城市、区域特征。
- **物理**：运动与力（力是维持运动的原因、惯性是力、重的物体下落快）、压强与浮力（浮力与深度/重量）、声与光（声音能在真空传播、平面镜成像大小随距离变）、热（温度与热量、熔化吸热）、电（电流被用电器消耗掉、串并联判断、电压与电流）、能量。
- **化学**：物质变化（物理变化 vs 化学变化）、微粒观（分子大小随温度变、物质由分子构成就以为都由分子构成）、质量守恒、化学式与化合价、酸碱盐、溶液（溶液一定无色、饱和就是浓）、燃烧与灭火、实验操作安全。
- **生物学**：细胞与结构层次、光合作用与呼吸作用（植物白天不呼吸、植物的质量来自土壤）、营养与消化、血液循环、遗传与变异、进化（用进废退）、生态系统（食物链箭头方向）、传染病与免疫。
- **科学**（小学）：物体与材料、水与空气、力与运动、声光热电、植物与动物、人体、天气与地球、宇宙；用简单的实验现象和生活情境出题，适合低年级的题干要短。
- **信息科技**：信息与数据、编码（二进制、编码的作用）、算法（顺序、分支、循环、算法不是程序）、网络与安全（密码、隐私、文件删除、网络信息真假）、物联网（传感器、控制）、人工智能（AI 会出错、AI 怎样学习）。
- **体育与健康**：健康知识（用眼、睡眠、饮水、营养、心理）、安全与急救（运动损伤冷敷、溺水、中暑）、运动原理（热身、心率、体能练习方法）、运动规则（常见球类规则）。用文字能说清楚的题，不出需要做动作才能判断的题。
- **音乐**：音乐要素（节拍、强弱规律、速度、力度、音色、音高）、记谱（简谱的唱名与音符时值、休止符、附点）、乐器分类与音色、中外代表作品和作曲家、民族音乐（戏曲剧种、民歌体裁）。拍号写成“2/4 拍”。
- **美术**：色彩（三原色、间色、冷暖色、对比色）、造型（透视的近大远小、比例、构图）、中国画（工笔与写意、笔墨）、设计（对称与均衡、实用与美观）、工艺与非遗、中外名作与作者、影视（镜头与景别）。
- **劳动**：劳动方法与步骤的先后（洗碗、整理、烹饪）、工具和器具的安全使用、食品安全与营养、种植养殖常识、传统工艺材料与步骤、劳动安全（用电、刀具、高温）。
